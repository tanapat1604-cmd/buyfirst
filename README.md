# BuyFirst

แอปจัดลำดับของน่าซื้อ ภาษาไทย ใช้ HTML/CSS/JavaScript โดยไม่ต้องติดตั้งแพ็กเกจ

## เริ่มใช้งาน

ดาวน์โหลด repo แล้วเปิด `index.html` ในเบราว์เซอร์ หรือใช้ VS Code Live Server เพื่อให้มี origin คงที่สำหรับ localStorage

## ฟีเจอร์

- เพิ่ม แก้ไข ลบรายการ พร้อมราคาและลิงก์สินค้า
- ให้คะแนนความจำเป็น ความเร่งด่วน และความอยากได้ ตั้งแต่ 1–5
- คะแนนรวม = ความจำเป็น × 10 + ความเร่งด่วน × 6 + ความอยากได้ × 4 (เต็ม 100)
- คะแนนเท่ากันเรียงราคาต่ำก่อน
- จัดแผนซื้อจากอันดับสูงลงมา ข้ามรายการที่เกินงบที่เหลือ ไม่ใช่อัลกอริทึมหาชุดสินค้าที่ให้คะแนนรวมสูงสุด
- ซื้อแล้วจะหักราคาออกจากงบ สูงสุดเท่ากับงบที่เหลือ ย้ายกลับลิสต์จะคืนจำนวนที่หักไป
- เก็บข้อมูลใน localStorage ของเบราว์เซอร์ ไม่มีบัญชีหรือการซิงก์ข้ามเครื่อง การล้างข้อมูลเว็บไซต์จะลบรายการ

## ตรวจสอบ

ตรวจไวยากรณ์ JavaScript ผ่านแล้ว ยังไม่ได้ทดสอบผ่านเบราว์เซอร์จริงในสภาพแวดล้อมสร้างนี้ เนื่องจากไม่มี browser executable
